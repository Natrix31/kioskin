# Kioskin HTTP API

Версия: 1.0  
Базовый URL: `http://localhost:8282`

**Swagger UI:** [http://localhost:8282/docs](http://localhost:8282/docs) — интерактивная документация, встроенная в приложение (без внешних CDN).

Локальный REST API без аутентификации. Предназначен для управления оверлей-окном из скриптов, CI или других сервисов на той же машине.

## Общие сведения

| Параметр | Значение |
|----------|----------|
| Протокол | HTTP/1.1 |
| Порт | `8282` (зашит в коде) |
| Аутентификация | нет |
| CORS | не настроен |
| Content-Type | см. описание эндпоинтов |

### Коды ответов

| Код | Значение |
|-----|----------|
| `200` | Успех |
| `405` | Неподдерживаемый HTTP-метод |
| `500` | Внутренняя ошибка сервера |

Текстовые ошибки (`405`, `500`) возвращаются в теле ответа plain text на русском языке.

## `GET /health`

Проверка, что HTTP-сервер запущен и отвечает.

### Запрос

Без тела и параметров.

### Ответ `200 OK`

```http
Content-Type: application/json
```

```json
{"status":"ok"}
```

### Пример

```bash
curl -i http://localhost:8282/health
```

## `GET /monitors`

Возвращает список мониторов в порядке, используемом Windows (`EnumDisplayMonitors`). Индексы совпадают с полем `monitor_index` в `config.json`.

### Запрос

Без тела и параметров.

### Ответ `200 OK`

```http
Content-Type: application/json
```

Массив объектов:

| Поле | Тип | Описание |
|------|-----|----------|
| `index` | `int` | Порядковый номер монитора (с `0`) |
| `left` | `int32` | Левая координата прямоугольника (px) |
| `top` | `int32` | Верхняя координата (px) |
| `right` | `int32` | Правая координата (px) |
| `bottom` | `int32` | Нижняя координата (px) |
| `width` | `int32` | Ширина (`right - left`) |
| `height` | `int32` | Высота (`bottom - top`) |

### Пример ответа

```json
[
  {
    "index": 0,
    "left": 0,
    "top": 0,
    "right": 1920,
    "bottom": 1080,
    "width": 1920,
    "height": 1080
  },
  {
    "index": 1,
    "left": 1920,
    "top": 0,
    "right": 3840,
    "bottom": 1080,
    "width": 1920,
    "height": 1080
  }
]
```

### Ошибки

| Код | Условие |
|-----|---------|
| `500` | Не удалось получить список мониторов |

### Пример

```bash
curl http://localhost:8282/monitors
```

## `POST /update`

Принимает произвольное тело запроса, форматирует его как JSON (с отступами, если валидный JSON) и отображает в окне. Делает окно полностью непрозрачным.

### Запрос

```http
POST /update HTTP/1.1
Content-Type: application/json   # рекомендуется, но не обязателен
```

**Тело:** произвольные байты. Если тело — валидный JSON, оно pretty-print'ится с отступом в 2 пробела. Иначе отображается как есть (raw string).

Ограничений на размер тела в коде нет (ограничение — доступная память).

### Ответ `200 OK`

```http
Content-Type: text/plain; charset=utf-8
```

```
JSON получен: окно обновлено и сделано непрозрачным
```

### Побочные эффекты

- Текст в окне заменяется на отформатированное содержимое.
- Альфа-канал окна: `255` (непрозрачно).

### Ошибки

| Код | Условие |
|-----|---------|
| `405` | Метод не `POST` |
| `500` | Ошибка чтения тела запроса |

### Примеры

```bash
# JSON
curl -X POST http://localhost:8282/update \
  -H "Content-Type: application/json" \
  -d '{"name":"order","id":123}'

# Не-JSON (отобразится как есть)
curl -X POST http://localhost:8282/update \
  -d 'plain text message'
```

## `GET /clear`

Сбрасывает окно в начальное состояние: текст `.`, полупрозрачный режим.

### Запрос

Без тела и параметров.

### Ответ `200 OK`

```http
Content-Type: text/plain; charset=utf-8
```

```
Окно очищено и переведено в полупрозрачный режим
```

### Побочные эффекты

- Текст в окне: `.`
- Альфа-канал окна: `50` (~20% непрозрачности)

### Ошибки

| Код | Условие |
|-----|---------|
| `405` | Метод не `GET` |

### Пример

```bash
curl http://localhost:8282/clear
```

## `GET /socials`

Разворачивает окно на весь выбранный монитор, делает его полностью непрозрачным и отображает изображение `assets/socials.png`.

### Запрос

Без тела и параметров.

### Ответ `200 OK`

```http
Content-Type: text/plain; charset=utf-8
```

```
Окно развёрнуто на весь экран, показана картинка socials
```

### Побочные эффекты

- Размер окна: весь монитор (`monitor_index` из `config.json`).
- Альфа-канал окна: `255` (непрозрачно).
- Отображается `assets/socials.png`, вписанная по центру с сохранением пропорций; текст и логотип скрываются.
- Возврат к обычному режиму — через `POST /update` или `GET /clear`, которые восстанавливают исходный (половинный) размер окна.

### Замечания

- Картинка встроена в бинарник (`go:embed assets/socials.png`) и загружается один раз при старте. Чтобы заменить изображение, обновите файл и пересоберите приложение.
- Если файл не удалось декодировать при старте, окно всё равно развернётся на весь экран и станет непрозрачным, но картинка не отобразится (в лог пишется ошибка).

### Ошибки

| Код | Условие |
|-----|---------|
| `405` | Метод не `GET` |

### Пример

```bash
curl http://localhost:8282/socials
```

## `GET /shutdown`

Инициирует graceful shutdown: останавливает HTTP-сервер (таймаут 5 с) и закрывает активное окно. Повторный вызов во время shutdown идемпотентен.

### Запрос

Без тела и параметров.

### Ответ `200 OK`

Первый вызов:

```
Graceful shutdown запущен
```

Повторный вызов (shutdown уже идёт):

```
Graceful shutdown уже выполняется
```

### Побочные эффекты

- HTTP-сервер переходит в состояние `Shutdown`.
- Активное GUI-окно закрывается.
- Приложение завершает работу.

### Ошибки

| Код | Условие |
|-----|---------|
| `405` | Метод не `GET` |

### Пример

```bash
curl http://localhost:8282/shutdown
```

## Типичные сценарии

### Kiosk / информационная панель

1. Запустить `kioskin.exe` с нужным `monitor_index`.
2. По событию из внешней системы — `POST /update` с JSON-данными.
3. По таймауту или событию «скрыть» — `GET /clear`.
4. При остановке сервиса — `GET /shutdown`.

### Выбор монитора

```bash
curl -s http://localhost:8282/monitors | jq .
# Записать нужный index в config.json → перезапустить приложение
```

### Healthcheck в оркестраторе

```bash
curl -sf http://localhost:8282/health | jq -e '.status == "ok"'
```

## Ограничения и замечания

- API доступен только на `localhost:8282`; смена порта не предусмотрена конфигурацией.
- Нет TLS, токенов и rate limiting — не экспонировать порт наружу.
- Обновление окна происходит в UI-потоке Windows; при очень частых запросах возможна очередь на `UiThread`.
- Если окно ещё не создано (между перезапусками), `POST /update` и `GET /clear` обновят внутреннее состояние, но визуально применятся только после появления окна.
