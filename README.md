# Kioskin

Windows-приложение с полупрозрачным оверлей-окном и локальным HTTP API для управления содержимым и состоянием окна.

Окно по умолчанию занимает верхнюю половину выбранного монитора. Текст отображается в статическом поле внутри окна. Прозрачность управляется через API.

## Требования

- Windows
- Go 1.25+

## Запуск

```bash
go run .
```

или (рекомендуется для распространения — без окна консоли):

```bash
go build -ldflags="-H=windowsgui" -o kioskin.exe .
.\kioskin.exe
```

Флаг `-H=windowsgui` собирает приложение в GUI-подсистеме Windows: окно
консоли не открывается. Приложение ничего не пишет в консоль (логирование
отключено).

После запуска HTTP-сервер слушает порт **8282**:

```
http://localhost:8282
```

Интерактивная документация API (Swagger UI): **http://localhost:8282/docs**

## Конфигурация

Файл `config.json` в рабочей директории:

```json
{
  "monitor_index": 0,
  "logo_path": "logo.png"
}
```

| Поле | Тип | По умолчанию | Описание |
|------|-----|--------------|----------|
| `monitor_index` | `int` | `0` | Индекс монитора для размещения окна (см. `GET /monitors`) |
| `logo_path` | `string` | — | Путь к PNG/JPEG логотипу. Если не задан или файл не найден — используется встроенный `assets/logo.png` |

Если файл отсутствует, повреждён или индекс вне диапазона — используется монитор `0` или основной экран.

## API

Подробное описание эндпоинтов: [docs/API.md](docs/API.md).

Машиночитаемая спецификация: [openapi.yaml](openapi.yaml).

| Метод | Путь | Описание |
|-------|------|----------|
| `POST` | `/update` | Показать JSON в окне, сделать окно непрозрачным |
| `GET` | `/clear` | Очистить окно, вернуть полупрозрачный режим |
| `GET` | `/socials` | Развернуть окно на весь экран и показать `assets/socials.png` |
| `GET` | `/health` | Проверка доступности сервиса |
| `GET` | `/monitors` | Список подключённых мониторов |
| `GET` | `/shutdown` | Graceful shutdown приложения |
| `GET` | `/docs` | Swagger UI (редирект на интерактивную документацию) |
| `GET` | `/openapi.yaml` | OpenAPI-спецификация (встроена в бинарник) |

### Быстрый пример

```bash
# Проверка
curl http://localhost:8282/health

# Показать данные
curl -X POST http://localhost:8282/update \
  -H "Content-Type: application/json" \
  -d '{"order_id": 42, "status": "ready"}'

# Очистить окно
curl http://localhost:8282/clear

# Показать socials-картинку на весь экран
curl http://localhost:8282/socials

# Список мониторов
curl http://localhost:8282/monitors
```

## Поведение окна

- **Начальное состояние:** текст `.`, прозрачность ~20% (`alpha = 50`).
- **После `/update`:** логотип отображается сверху по центру, под ним — pretty-printed JSON; прозрачность 100% (`alpha = 255`).
- **После `/clear`:** логотип скрывается, текст сбрасывается в `.`, прозрачность возвращается к ~20%, окно возвращается к половинному размеру.
- **После `/socials`:** окно разворачивается на весь выбранный монитор, прозрачность 100% (`alpha = 255`), текст и логотип скрываются, по центру показывается `assets/socials.png` (вписана с сохранением пропорций). `/update` и `/clear` возвращают окно к половинному размеру.
- Окно без рамки (`WS_POPUP`), заголовок — `Kioskin`.
- При закрытии окна пользователем приложение пересоздаёт его (цикл в `main`), пока не вызван `/shutdown`.

## Иконка

Иконка приложения встроена в бинарник через ресурс `rsrc.syso` (Windows
использует её как иконку `.exe`). Исходный `.ico` — `assets/icon.ico`,
сгенерирован из `assets/logo.png` (логотип вписан по центру квадрата с
сохранением пропорций, размеры 16–256 px).

Чтобы обновить иконку после смены логотипа:

```bash
# 1. Пересобрать assets/icon.ico из логотипа
go run ./tools/genico assets/logo.png assets/icon.ico

# 2. Перегенерировать ресурс rsrc.syso
go run github.com/akavel/rsrc@latest -ico assets/icon.ico -o rsrc.syso

# 3. Пересобрать приложение (go build подхватит rsrc.syso автоматически)
go build -ldflags="-H=windowsgui" -o kioskin.exe .
```
